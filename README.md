## 자료 추가하는 법

1. 자료마다 폴더를 하나 만든다. 폴더 이름은 짧은 영문 kebab-case, 날짜 없이 (`aitop100-prelim`).
2. 폴더 안에 `index.html` 과 필요한 파일(`assets/` 등)을 넣는다. 원본은 비공개 작업 저장소에 두고, 공개해도 되는 사본만 여기에 복사한다.
3. 루트 `index.html` 목록 맨 위에 항목을 하나 더하고, 이 README 표에도 한 줄 더한다.
