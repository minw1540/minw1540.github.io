## 자료 추가하는 법

1. 자료마다 폴더를 하나 만든다. 이름은 짧은 영문 kebab-case, 날짜 없이 (`aitop100-prelim`).
2. 폴더 안에 `index.html`과 필요한 파일(`assets/` 등)을 넣는다. 원본은 비공개 작업 저장소에 두고, 공개해도 되는 사본만 복사한다.
3. 링크 미리보기용 표지 그림(1200×630)을 `assets/og.jpg`로 두고, 자료 `index.html`에 `og:` 정보를 넣는다.
4. 루트 `index.html`의 갤러리와 표 양쪽 맨 앞에 한 건씩 더한다. 등록번호는 이어서 매기고, 아래 건수도 고친다.
5. 이 README의 「등록된 자료」 표 맨 위에 한 줄 더한다.
